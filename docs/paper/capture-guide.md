# 論文用UIキャプチャとシステム図

現行WISS実装（2026-10-14）のコードに基づく。既存READMEに残る旧実験の自動姿勢解析・段階的指示は、本図の対象に含めない。

## 推奨する図の構成

主図は「(a) 被写体の撮影中画面」を大きく上段に配置し、下段に「(b) 撮影者画面」「(c) 代表者の提案・確定画面」を並べる。役割別の見え方と、被写体が撮影方針に関与する仕組みが同時に伝わる。紙面が厳しい場合は(a)(b)を本文、(c)を別図にする。

|優先度|キャプチャする画面・入口|撮る状態と残す範囲|伝わること|
|---|---|---|---|
|必須 (a)|iOSアプリで参加後の横向き主画面|左のお手本写真、右の「撮影者の映像＋フレーム」、画面上部のフレーム名・代表者表示、下部の操作ボタンを含める|被写体が撮影者の視点を参照し、自分たちの位置・ポーズを調整できる|
|必須 (b)|撮影者Web `/booth/`|カメラ開始・フレーム確定後。映像＋フレーム、「撮影する」、参加人数・代表者・グループの提案を残す|撮影者と被写体が共通のガイドを参照する|
|推奨 (c)|代表者のiOS「フレームを選ぶ・提案」|別の被写体から提案が届き、「グループからの提案」と「この提案を確定」が見える状態。種類の選択を説明する場合は参照写真を選択した状態も別途撮る|各自の提案と代表者による確定の区別|
|再利用を主張する場合 (d)|管理Web `/admin/` の「手描きフレーム登録」|お手本写真とPNGを指定した重畳プレビューを切り出す|研究者が手描き素材を確認・登録する仕組み|

ログイン、参加コード入力、同意回答、空のライブラリだけでは中心機能が伝わりにくい。保存ダイアログと共有ギャラリーは、保存・共有自体を説明する場合の補助図にする。

## キャプチャ手順

1. 掲載に使用できる人物写真をお手本として用意し、対応するボックス・シルエット・ボックス＋顔位置の3種類の透過PNGを管理画面から登録・公開する。本文の主画面には人物との対応が読み取りやすい種類を1つ選ぶ。
2. 撮影者が `/booth/` でセッションとカメラを開始する。被写体2〜3人がiOSアプリから同じセッションに参加し、各自が同意項目に回答する。6人は上限であり、図のために6人を揃える必要はない。
3. 代表者以外がフレームを提案する。代表者端末で(c)を撮り、その提案を確定する。
4. フレームが撮影者と各被写体端末に反映され、映像が届いていることを確認する。人物がフレームに合わせて調整している途中で(a)(b)を撮る。同じお手本・フレーム・撮影場面を使う。
5. iOS実機では端末のスクリーンショット、Simulatorでは「File → Save Screen」を使う。WebはOSの範囲指定キャプチャなどで取得する。論文にはUI内の画像領域の縦横比を変えずに配置する。
6. QRコード、参加コード、共有URLは論文掲載画像でマスクする。図注にマスクした旨を記す。UI文字や状態を加工して、実装にない操作を追加しない。

接続待ちや黒画面ではなく、実際に人物が映りフレームが重なった状態を使う。模擬映像を使った場合は「デモ用映像」と明記する。今回の作業ではキャプチャ画像の取得は行っていない。

## キャプション案

**UI図：** 協調撮影インタフェース。(a) 被写体はお手本写真と、撮影者の映像に共通フレームを重畳した表示を並べて参照する。(b) 撮影者は同じフレームを参照して構図を調整し、撮影する。(c) 被写体はフレームを提案でき、代表者が撮影に使用するフレームを確定する。参加・共有用のコードは掲載時にマスクした。

**システム図：** システム構成。撮影者Webのカメラ映像をサーバ経由で被写体のiOS端末に配信し、確定フレームを端末間で共有する。撮影画像・同意情報・操作ログを永続化し、保存判断と研究同意に従って外部保存を行う。公開同意のある自由撮影写真をもとに研究者がフレームを手描きし、公開ライブラリへ追加できる。

## 本文で区別する実装上の点

- 映像はWebRTCやLiveKitではなく、WebSocketによるJPEG中継。確定フレームの重畳は各クライアントで行い、保存写真には焼き込まない。
- フレームは自動姿勢推定の生成物ではなく、研究者の手描きPNG。3種類はボックス、シルエット、ボックス＋顔位置。
- 共有保存、研究保存、公開再利用を区別する。研究利用と公開利用の同意は独立しており、撮影時の全員の同意を記録する。
- 写真から公開ライブラリへの追加には、研究者による手描き・登録・公開操作が入る。自動生成・自動公開の循環として描かない。
- 操作ログは記録できるが、再現精度の向上や協調性の改善はこのコード確認だけでは示せない。評価結果として書くには別途実験が必要。
